Provider resource-link pack

Keep materials with the provider. Give the family one clear, working link.

← Practice tools

Who maintains what?

Each provider stores, prepares and maintains their own resources. They send one stable link for their area on the child’s START page, with the access already arranged and tested.

The family’s Google Drive is for instruction manuals, setup information, invitation templates and a small number of agreed visual supports or small files. It is not the default storage location for provider materials. The family should not have to download, sort, rename and re-upload everybody’s therapy files.

The family controls which provider links appear on START, agreed weekly practice targets and access to any family-held information. The clinician or setup support can configure the initial links where needed. Private provider links and family information must not be published in this public pack.

1. Provider: choose a place for your resources
  1. Use your existing organisation-approved resource space where possible: a client portal, a SharePoint/OneDrive folder, an approved Google Drive folder owned by your service, or an approved resource board. A provider does not have to use Google Drive.
  2. Keep that client’s activity page or folder separate from unrelated client records. Add only materials the child/family are meant to use.
  3. Arrange suitable family access. Use named recipients or the service’s approved guest access where appropriate. Tell the family whether a login is required; do not send passwords in the link.
  4. Give the family one stable landing link for your service, with a few ready activities. Keep child-facing choices obvious and put longer adult guidance alongside them.
  5. Test the link on a tablet as the family would open it. A link working while you are signed into your own work account is not enough. Resolve access problems with your service rather than asking the family to rebuild your folder.

Use the platform and access arrangements your service approves. Storage, licensing, guest access and available features vary; no purchase or public sharing is assumed.

2. Provider: maintain your link and activities
  1. Send the link, your name/discipline and suggested weekly frequency to the family or setup clinician.
  2. Keep the same link when replacing activities. Mark each current week Monday to Sunday. Archive old work within your own space so the current choices remain clear.
  3. Include the activity information below. Demonstrate unfamiliar activities and keep a clear finished point.
  4. If a link must change, send the replacement and explain what changed. The setup person updates the corresponding START field once.
  5. Tell the family when work is paused, no longer suitable or no longer available. Agree handover/export of needed materials if your service ends.

The family can check completed practice and choose whether to share reports. A website opening does not prove completion, and a practice count alone is not clinical progress.

3. Activity and appointment format

Download the reusable provider format

Activity

  • Consistent picture/symbol, exact activity name, provider and discipline.
  • Aim and recommended practices per week; family-agreed target or TBC.
  • Monday start date and Sunday end date for the planned week.
  • Direct activity link, or exact physical-resource location.
  • Materials, 2–3 short directions and pictures/demonstration.
  • Adult support and consistent cues.
  • Clear finished point; duration/amount; how to simplify, pause or ask for help.

Actual appointment

Use the same symbol plus discipline and provider in the title. Include the actual date/time/timezone, location or Join link, what will happen and anything needed. Examples: 💬 Speech, 💪 OT, 🌱 PBS, 🏫 School, 🤝 Support worker. Agree symbols with the family.

Practice reminders tell the child to return to START and choose an activity unless an actual appointment is booked. Providers recommend weekly frequencies; they do not need to create artificial bookings for every practice choice.

4. Parent or setup support: connect the links
  1. On the child’s Samsung, open the saved START file in its usual browser.
  2. Open Family setup (or the parent setup section in that version), then Links.
  3. Paste each provider-supplied URL into its Speech, OT, PBS, School or Support worker field. A service button opens that provider’s resource space; it need not point to the family Drive.
  4. Use the family’s admin folder link only for Shared resources / instructions, and a creations link only if agreed.
  5. Save setup, approve if asked and test each provider link on the child’s tablet. Save a full backup afterwards.

Editing a downloaded HTML on another computer does not automatically update the Samsung. Updating resources behind an unchanged provider link does not require a new HTML file. A live page at this public address updates after publishing and refreshing; it does not update the child’s downloaded START.

5. Calendar, weekly targets and activity records

Calendar invitation access, provider portal access, Google Contacts and family Drive permissions are separate. To show future Google Calendar invitations from known providers, save their sending emails as contacts and select Settings → General → Event settings → Add invitations to my calendar → Only if the sender is known. This adds invitations to the calendar; it is not an automatic Yes RSVP.

Set weekly activity targets in the child’s own START parent settings. Counts run Monday to Sunday; targets and calendar reminder times are separate. Follow the child’s current individual plan rather than a timetable in this generic pack.

Return to START after an outside activity and record completion using that version’s tracker. If using the coin version, one whole approved activity adds one coin; a whole routine is one activity. The parent approval control is in Coin collection → parent-check section → Check and approve. Use the family’s agreed code privately. Other versions may use a footy tracker rather than coins.

Recordings and activity data in a downloaded START remain on that device/browser. A parent chooses whether to export/share a report. Hosting resources on GitHub or in a provider folder does not provide live access to the child’s tracker or send automatic emails.

6. Invitation template for the family to adapt

Select and copy this draft. Add the child’s name and actual contact/access details privately before sending.

Hi everyone,

We have set up a visual START page so our child can find ready therapy and school activities, choose what to practise and record how it went. We would like the team to contribute so the language, cues and learning targets are consistent across settings.

Could each provider please supply one stable link to resources you store and maintain in your own service’s approved space? The family’s Drive is for manuals, setup information and small agreed supports; we are not asking the family to host or manage everyone’s therapy materials.

Please arrange and test family access, explain any login requirement and keep your current choices clear. Let us know if the link changes. Where useful, the setup clinician can add the initial link to START.

For each activity, include your name/service, title/aim, suggested frequency, Monday–Sunday dates, direct link or physical location, materials, brief picture-supported directions, cues/support, finished point and simplify/pause options. Please demonstrate unfamiliar tasks and agree the active weekly target with the family.

We favour choice among suitable activities rather than allocating every practice window to a discipline. Actual appointments should still be sent to the child’s agreed calendar address, using a consistent symbol plus discipline/provider, time, location or Join link and materials.

Please help us align class and therapy targets where appropriate. The family controls access to family records and decides whether to share activity reports. The tracker records participation and support; it is not a clinical progress measure.

Please send your resource link, suggested starting activities and the best work contact for access questions.

Thanks,
[Parent/carer]
