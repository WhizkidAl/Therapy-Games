# Shared learning tools

Published address: https://whizkidal.github.io/Therapy-Games/shared-tools/

Generic child-facing landing page for Whiz Kids tools. Contains no participant data.

To add a game, PDF, worksheet or book:
1. Store it in its primary therapeutic domain folder, using a lowercase, hyphen-separated generic filename.
2. On GitHub open that folder, choose Add file > Upload files, then Commit changes.
3. Edit shared-tools/index.html and add a card with a relative link to the resource. Copy an existing card, change its title, description and href.
4. Commit changes and wait for the Pages deployment. Refresh the published page and test its link on a tablet.
5. Give families the same shared-tools address; the directory updates remotely.

Replacing a file at the same path preserves its resource link. Adding a file alone does not add a homepage card. A private parent-maintained START page links to this generic public directory. Family calendars, provider links, participant avatars, personalised schedules and session data remain outside this repository.

phonics.html reproduces the existing extended blue-and-gold letter-tile inventory, without participant details. It is an open-ended word-building tool, not an assessment or an automatically prescribed sequence. No speech or pronunciation audio is implied. Word building is temporary and clears on reload.
