# Therapy Games

A growing library of browser-based therapy activities for supported clinical use.

The repository is organised by **primary therapeutic domain**, with subcategories added only when there is an actual game to place within them. This keeps the library easy to navigate and avoids creating empty folder structures.

## Library domains

### 1. Speech & Language

Primary folder: `speech-language/`

Planned subcategories:

- `semantics/` — vocabulary knowledge, semantic networks, semantic differentiation and word relationships
- `receptive-language/` — understanding spoken language, concepts and instructions
- `expressive-language/` — formulation, vocabulary retrieval, grammar and sentence generation
- `narrative/` — story grammar, sequencing, cohesion, inference and retell
- `speech-sounds/` — articulation, phonology and speech-sound practice
- `pragmatics/` — communication interpretation and use where the primary target is pragmatic language

Current game:

- **Word Detective — Semantic Differentiation**: explicit semantic feature comparison, contrastive word-choice challenges and narrative application.

## Classification rule

Each game should live in one primary folder based on its **main therapeutic target**. If a game supports multiple areas, use tags and homepage descriptions to show secondary targets rather than storing duplicate copies of the same game.

For example, Word Detective targets semantic differentiation most directly, so it lives in:

`/speech-language/semantics/`

Even though it also supports receptive language and narrative use.

## Naming conventions

Use clear, generic, de-identified filenames:

- lowercase
- hyphen-separated
- based on the therapy target or game name
- no participant names or initials

Example:

`semantic-word-detective.html`

## Privacy and clinical governance

This repository contains **generic therapy resources only**.

Do not include:

- participant names or initials
- dates of birth
- NDIS numbers
- contact details
- clinical notes
- assessment results
- therapy-session records
- any other participant-identifiable information

Session results generated by current HTML games should remain local to the browser unless a future version explicitly states otherwise.

Game scores are **informal therapy data**, not standardised assessment scores. Clinical interpretation should consider prompting, explanation quality, persistence, generalisation and functional performance alongside accuracy.

## Therapist-facing access

`index.html` is the therapist-facing library homepage. Therapists should normally access games through the published GitHub Pages site rather than navigating the repository itself.
