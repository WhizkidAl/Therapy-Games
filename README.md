# Therapy Games

A small library of browser-based therapy activities.

## Current games

- **Word Detective — Semantic Differentiation**: explicit semantic feature comparison, contrastive word-choice challenges, and narrative application.

## Privacy and clinical governance

This repository is intended to contain **generic therapy resources only**.

- Do not include participant names, dates of birth, NDIS numbers, clinical notes, assessment results, contact details, or other identifiable information.
- Session results generated by the current HTML games are held only in the browser session unless a future version explicitly states otherwise.
- Game scores are informal therapy data, not standardised assessment scores.

## Structure

- `index.html` — therapist-facing game library homepage
- `semantic-word-detective.html` — semantic differentiation game
