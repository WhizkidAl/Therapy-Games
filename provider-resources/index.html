In one minute

  1. Choose a location: your existing Google Doc, SharePoint/OneDrive folder, Padlet or other appropriate service.
  2. Send a stable viewing link (or a permitted PDF/document) to the parent, with frequency and brief cues.
  3. Keep updating it: if the link does not change, the family generally doesn't need to edit the START link.
  4. Request a named practice slot only when needed; otherwise the child chooses among available activities at the family's ordinary practice times.
Privacy: This public website contains generic instructions only. Do not post a child's name, schedules, provider appointments, email addresses, personalised clinical records, passwords or restricted resource links in GitHub. Those belong in the family's private communications and shared workspace.
