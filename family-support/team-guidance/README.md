# Shared home-practice setup: reusable team guidance

Use the provider activity and calendar format alongside a family-controlled resource folder and visual START page. Keep personalised resources, backups, contact lists and clinical records outside this public repository.

## Folder structure
The family owns the main folder. Share each service folder with its providers and a common Visual supports folder with the agreed team. Keep Parent setup & instructions and backups restricted to the family and agreed setup support. Main-folder permissions normally inherit to children: do not share the root with everyone if service folders are meant to differ.

## Provider contribution
State activity name/aim, recommended weekly frequency, Monday start/Sunday end dates, direct link or precise paper location, materials, picture-supported instructions, cues, finished point and simplify/pause options. The family agrees active weekly targets; recurring choice reminders are separate from actual appointments.

## Calendar
Use a consistent symbol plus discipline and provider. Include actual time/timezone, place/Join link, materials and support. Known-sender auto-add is not an automatic RSVP. Save provider invitation emails in the child's contacts and configure Google Calendar invitations as agreed. Calendar sharing, Drive access and subscription logins are separate.

## Activity records
Opening an external link does not verify completion. A family-reported activity can be recorded with visual feedback and parent approval. Where a collection model is used, one whole approved activity adds one coin; a whole routine is one activity. Keep any external family reward arrangement separate. Avoid claims of clinical progress based only on clicks or frequency.

## Sharing records
A downloaded HTML's local storage does not provide remote team access. A parent can deliberately export/share a report; hosting a page alone does not create secure cross-device record synchronisation. Do not publish private backups or put codes/passwords in templates.
