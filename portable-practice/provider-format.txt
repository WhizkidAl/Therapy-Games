PROVIDER-OWNED RESOURCE LINKS
Each provider stores and maintains its materials, arranges family access and supplies one stable link. Family Drive is for admin documents and small agreed supports, not a central provider materials store.

PROVIDER ACTIVITY AND CALENDAR FORMAT
Use one consistent symbol AND the written discipline name: Speech 💬; OT 💪; PBS 🌱; School 🏫; Support worker 🤝; Tutor 📝 if involved. Agree symbols with the family. Keep them consistent across resources, appointments and START.

Recommend a frequency; the family sets the active target in Family setup > Weekly frequency and practice choices > Save setup. Blank is TBC, not zero. New weekly counts start on Monday; earlier weeks remain. Keep full instructions with the activity so the parent only needs to enter its frequency in START.

COMPLETION
For a resource opened from START: return to the same START file/browser > Finished or need help > answer the three picture questions > Finished. For a separate paper/offline activity: START > I did an offline activity > choose its picture > questions > Finished. For a whole paper routine: open Morning or Afternoon routine > I finished on paper. A whole routine is one activity; do not claim a coin for each step as well.
Reported outside/offline work waits at START > Coin collection > Parent checks > Check and approve. A parent enters the agreed code privately. One whole approved activity adds one coin. Stopped saves feedback without a coin. Difficulty or needing help does not cancel a completed activity's coin. Opening a website is not verified completion. Built-in checked word work has its own completion rule; outside programmes do not send automatic completion data to START.
